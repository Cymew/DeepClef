# DeepClef 宣传片制作方案

> 目标：让刷到视频的人在 10 秒内看懂"这是 AI 在自己玩 Minecraft"，并在结尾愿意点进 GitHub / 下载模组。

---

## 一、定位

| 项目 | 内容 |
|---|---|
| 核心卖点 | 不是"脚本机器人"，而是**能看见、能思考、能临场调整**的 AI 玩家 |
| 记忆点一句话 | "Don't Just Automate. Think." / "它不只是自动执行，它在思考" |
| 目标观众 | MC 玩家（尤其玩 mod / 多人服）、AI 爱好者、想录 AI 玩游戏的 UP 主 |
| 观众情绪 | 前半段"好奇"→ 中段"惊讶"（它真的自己打怪/坐船/飞）→ 结尾"我也想要" |
| CTA（行动号召） | GitHub 仓库 + Releases 下载 + 需要自己的 DeepSeek API Key |

**不要做的事**：不要做成纯功能罗列（"支持 20 个指令…"）。观众只想看**它自己完成了一件完整的事**。

---

## 二、成品规格

| 版本 | 时长 | 比例 | 用途 |
|---|---|---|---|
| 主片 | 90~120 秒 | 16:9 / 1080p60 | YouTube、B站、GitHub Release 首页置顶 |
| 竖屏短片 | 30 秒 | 9:16 / 1080p60 | 抖音、B站动态、X/Twitter、小红书 |
| GIF 预览 | 8~12 秒 | 16:9 | README 顶部、Release 描述、Discord |

> 竖屏版只保留一个完整镜头：**打字 → 思考流 → 它自己打怪**。别塞功能。

---

## 三、主片分镜脚本（约 105 秒）

### 0:00–0:06｜冷开场（无字幕，只有环境音 + 音效）
- 画面：第一人称/第三人称镜头，长矛蓄力 → 突刺命中僵尸，慢动作 0.3×，命中瞬间轻微屏震
- 字幕：无
- 目的：用"看起来像真人操作"的画面抓住注意力

### 0:06–0:12｜标题卡
- 画面：黑底 / 游戏画面虚化压暗，居中大标题
- 文字：
  ```
  DeepClef
  Don't Just Automate. Think.
  ```
- 音效：低频"咚"一下

### 0:12–0:28｜"它能听懂人话"（核心镜头，最重要）
- 操作：打开聊天栏 → 打字 `@ds 帮我挖64个铁锭`
- 画面：右侧思考叠加层（thinking overlay）开始滚动文字；机器人跑出去开始挖矿
- 强调：**叠加层一定要清晰可读**，这是"它在思考"的唯一视觉证据
- 字幕：`你只需要说一句话` / `One sentence is all it takes`

### 0:28–0:45｜"它会观察"
- 操作：`@ds 你在哪？周围有什么危险？`
- 画面：叠加层依次出现 `altoclef_status` / `altoclef_look` / `altoclef_entities` 的工具结果；镜头轻微环视
- 字幕：`它会先侦查，再行动` / `It scouts before it acts`
- 剪辑提示：这段可以 1.3× 加速，只保留关键 3~4 行工具调用

### 0:45–1:05｜"它会战斗"（难度镜头）
- 操作：`@ds 清理附近的僵尸`（提前在附近放 4~6 只僵尸，或用刷怪笼）
- 画面：完整展示一次 **接近 → 瞄准 → 蓄力 → 突刺 → 后退** 的节奏
- 剪辑：慢动作重放一次命中帧；叠加层与画面并排/画中画
- 字幕：`26.3 新武器长矛，它也会用` / `It even fights with 26.3 spears`

### 1:05–1:25｜"它能移动"（展示广度）
- 操作 A：`@ds 坐船去 x=100 z=200`（走一段长水路或冰道）
- 操作 B：`@ds 用鞘翅飞到 1000 200 并降落`
- 画面：两个镜头各 8~10 秒，加速剪辑，保留"放船/起飞/着陆"三个关键动作
- 字幕：`水路、冰道、鞘翅，全部自己规划` / `Boats, ice roads, elytra — all planned`

### 1:25–1:38｜"它还能聊天"（差异化卖点）
- 画面：多人服务器，队友在公屏喊话
  ```
  <Alex> bot 能帮我打点木头吗
  [DeepClef] 好的，我去砍树，稍等
  ```
- 强调：`@ds chat on` 开启后，它会读聊天并回应
- 字幕：`多人游戏里，它能和你的队友配合` / `It talks to your teammates`

### 1:38–1:48｜收尾卡
- 画面：`@help` 指令列表快速滚动（2 秒）→ 白/黑底结尾卡
- 结尾卡文字：
  ```
  DeepClef — Minecraft 26.3 AI Agent
  github.com/Cymew/DeepClef
  需要一个 DeepSeek API Key
  ```
- 音频：音乐收尾 + 一声提示音

## 四、录制前准备清单

### 环境
- [ ] 用 **beta2 最新 jar**（`deepclef-26.3-beta2.jar`）
- [ ] 游戏窗口 1920×1080，`GUI 缩放 2`（画面清爽），关闭 F3 调试信息
- [ ] 录制：OBS，1080p60，码率 8~12 Mbps，录制 **MKV**（防崩溃丢文件）
- [ ] 关闭：手机通知、系统弹窗、右上角聊天外的其他 mod 提示

### 世界准备（一次性搭好，之后连续录）
- [ ] 一个平坦、资源丰富的位置作为"基地"（挖矿镜头起点）
- [ ] 附近预置 5~8 只僵尸（用刷怪笼 / 指令 `summon zombie`），并给玩家一把铁剑 + 长矛
- [ ] 一条 100~200 格的水路或冰道（船镜头）
- [ ] 一个高处起飞点 + 已装备鞘翅 + 烟花
- [ ] 一个多人测试服或局域网联机（聊天镜头），队友提前说好台词

### 安全（重要）
- [ ] **不要在镜头里露出 API Key**：录"首次配置界面"时遮住 key 输入框，或干脆不录配置界面
- [ ] 不要把设置文件、私聊内容、服务器 IP 录进去
- [ ] 录多人镜头时征得队友同意

### 素材备份
- [ ] 每次录完立刻把 OBS 文件复制一份到其他盘
- [ ] 单独录 3 个"备用空镜"：思考叠加层特写、命中慢动作、结尾 `@help` 滚动

## 五、剪辑建议

| 项目 | 建议 |
|---|---|
| 节奏 | 每 8~12 秒必须有画面上/字幕上的变化；AI 等待时间（模型响应 2~10 秒）全部剪掉或加速 |
| 加速规则 | 挖矿/走路/等待：2×~4×；战斗命中：0.3× 慢动作；思考叠加层：1.3× 稍慢便于阅读 |
| 叠加层可读性 | 游戏内先 `@dssize 1.0` 放大思考字；剪辑时对叠加层区域加 110% 缩放 + 轻微暗角 |
| 字幕 | 中英双语，底部居中，字号大（手机能看清）；关键词加亮色（如 `@ds`、`long spears`） |
| 音乐 | 电子/史诗节奏，避免版权风险（YouTube 音频库 / Pixabay Music）；0:06 标题卡处给一个重音 |
| 音效 | 命中"叮"、界面提示音、结尾"叮咚"；不要盖过人声（如果做配音） |
| 转场 | 只用两种：硬切 + 轻微白闪；不要花哨转场 |
| 配音 | 可选。有配音更好，但**中文配音 + 英文字幕**的版本传播性最好 |

## 八、常见坑

1. **AI 响应慢导致画面卡**：不要录完整等待过程，剪掉中间，用叠加层的"已思考 3 行"过渡
2. **叠加层字太小看不清**：一定要先 `@dssize 1.0`，剪辑时再放大
3. **机器人走得太久**：把基地到矿区的距离控制在 30 格内，或用 `@ds` 让它就地在附近挖
4. **战斗镜头不出彩**：多录几次，只留最漂亮的一次命中；必要时用 `/effect` 给僵尸加缓慢
5. **忘了遮 API Key**：录制前先把 key 填好，别录配置界面
6. **竖屏版直接裁 16:9**：不行，要在录制时单独用竖屏构图（或用 OBS 输出两份）

## 九、最小可行版本（如果时间紧）

只做这 3 个镜头也够传播：

1. **打字 `@ds 帮我砍树` → 叠加层滚动 → 它真的去砍了**（10 秒）
2. **`@ds 清理僵尸` → 长矛突刺命中慢动作**（8 秒）
3. **结尾卡 + GitHub 地址**（4 秒）

合计 25 秒，配一句"它自己在玩"就足够。
