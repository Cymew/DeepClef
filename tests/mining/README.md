# 挖掘回归

运行：`./gradlew miningRegression -I tests/mining.gradle`，使用项目配置的 Java 25 工具链。

覆盖实际 ItemStack 评分、原生 Inventory 槽位选择、背包单次交换、同类型附魔工具、同速稳定性、工具损坏、交换未确认，以及水中高度控制和低氧/补满氧气的状态边界。工具规则使用显式方块集合，因此不需要启动世界加载标签。高度回放使用普通水中纵向运动模型，不代替实机水流和碰撞验证。

2026-11-04：挖掘专项 66,942 项检查、传送门专项 2,713 项检查、既有综合回归 107,975 项检查及 build 通过。发布包中 678 个主类与本次编译结果逐字节一致。

游戏内复测步骤：

1. 同时携带木斧和铁斧，手持木斧开始砍树；分别把铁斧放在快捷栏和主背包。应切到铁斧后持续挖掘，快捷栏不反复切换。
2. 同时携带多把同类工具，其中一把有效率附魔；应选择具体的较快工具，同速工具不来回交换。
3. 在截图类似的水边挖岸上方块，以及在水下挖可触及方块；应维持可挖掘高度。氧气刚下降不应重启任务，低氧仍中断补氧，补满再继续。
4. 水中挖掘时停止任务或切换任务；不应残留跳跃输入。目标持续不可见超过 20 tick 时应释放高度保持并重新寻路。
